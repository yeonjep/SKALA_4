Welcome

SpringBoot로 리팩토링 된 방식으로, 로그인 인증이 성공적으로 완료되었습니다.
현재 사용자는 JWT Cookie 기반으로 인증되었습니다.

본 예제는 여러 역할이 하나의 클래스에 혼재하던 순수 Java 인증 서버를 Spring Boot 기반으로 리팩토링한 구조입니다.

SRP(Single Responsibility Principle)를 적용하여 Controller, Service, Repository, Security 영역의 책임을 분리하고, 유지보수성과 확장성을 높였습니다.

참고로, 일반적으로 사용자 로그인은 JWT Cookie 방식으로 구현하지만 향후 API 인증은 Bearer Token 방식으로 구현합니다.

✓ 인증 처리와 계층별 책임 분리가 정상적으로 적용되었습니다.
